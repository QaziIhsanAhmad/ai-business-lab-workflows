# AI Business Lab — three clips into one finished edit

Download [workflow-kit.zip](workflow-kit.zip?raw=true) for the three original animated clips, runnable Python/FFmpeg recipe, the local editor and actual export output.

Unzip and run `python3 tool/edit.py` with Python 3 and FFmpeg installed. Or run `python3 tool/serve.py` and open `http://127.0.0.1:8770/editor.html`.

This is a deterministic local editing recipe, not an AI choosing your story or generating unlimited video. Three 3-second original shots and two overlapping 0.35-second cross-fades produce an 8.3-second edit. No paid API or cloud account is used by this recipe. Hardware, installation, electricity and render time still apply.

All character/scene footage in the kit was created for this project. No reference creator footage or likeness is used. Source animation has 12 unique frames per second, encoded at 24 fps. The character is an illustrative helper, not a replacement brand logo. No customer data or credentials are included.
